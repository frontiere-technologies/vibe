# docs/

Project documents. Everything here is committed to Git.

- `superpowers/` — created by the Superpowers plugin: `specs/` (design documents approved before a change is built) and `plans/` (implementation plans written from the specs). It ships empty, with only a `.gitkeep`.
- `reviews/` — reviews of the work (code, design, quality).
- `second-brain/` — the project's knowledge base: sources, wiki and reports (see `second-brain/SCHEMA.md`).
