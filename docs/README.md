# docs/

Project documents. Everything here is committed to Git.

- `superpowers/` — if the Superpowers plugin is used, it creates this folder the first time it saves a document: `specs/` (design documents approved before a change is built) and `plans/` (implementation plans written from the specs). The template does not ship it.
- `reviews/` — reviews of the work (code, design, quality).
- `second-brain/` — the project's knowledge base: sources, wiki and reports (see `second-brain/SCHEMA.md`).
