# docs/

Project documents. Everything here is committed to Git.

- `superpowers/specs/` — design documents approved before a change is built.
- `superpowers/plans/` — implementation plans written from the specs.
- `reviews/` — reviews of the work (code, design, quality).
- `second-brain/` — the project's knowledge base: sources, wiki and reports (see `second-brain/SCHEMA.md`).
